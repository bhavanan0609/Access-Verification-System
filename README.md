 Intelligent Access Verification System

A Data Structures micro-project that simulates access control for a high-security biomedical research lab. It uses **queues** to manage people waiting for verification and **linked lists** to store and process access records. The core simulation is written in C++, and this repository also hosts a website that demonstrates the system.

 **Live Demo:** https://bhavanan0609.github.io/Access-Verification-System/

Data Structures Used
- **Queue:** handles the order in which people request access (first come, first served)
- **Linked List:** stores and manages access records dynamically

 Files
- `index.html`: project website
- `AccessVerificationSystem-code.pdf`: C++ source code
